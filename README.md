🎬 Streaming Store Demo

Proyecto frontend de una tienda virtual de productos digitales desarrollado como práctica de desarrollo web y frontend moderno.

🚀 Demo Online

🌐 https://latienditadelp.netlify.app/

💻 Repositorio

🔗 https://github.com/DavilaLP/Streaming

---

✨ Características

- 📱 Diseño responsive para móviles y PC
- 🛒 Carrito de compras
- 🔍 Búsqueda de productos
- 🎵 Categorías dinámicas
- 🌙 Interfaz dark mode
- ⚡ Navegación rápida
- 💳 Simulación de proceso de compra
